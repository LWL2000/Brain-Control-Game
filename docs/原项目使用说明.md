# SSVEP脑机接口程序使用说明

## 一、程序概述

本程序是一个基于Python的单通道SSVEP（稳态视觉诱发电位）脑机接口系统，主要用于通过脑电信号识别用户的视觉注意力，并将其转化为控制命令。

### 系统架构

程序分为两个主要模块：

1. **BLE数据采集模块**：负责通过蓝牙从脑电头环接收原始脑电数据
2. **SSVEP信号处理与识别模块**：负责显示视觉刺激、处理脑电数据、识别SSVEP信号并生成控制命令

### 核心功能

- 通过BLE（低功耗蓝牙）接收脑电头环数据
- 将原始脑电数据转换为LSL（Lab Streaming Layer）数据流
- 显示闪烁的视觉刺激界面
- 采集脑电数据并进行预处理（滤波等）
- 使用FBCCA（滤波器组典型相关分析）算法识别SSVEP信号
- 根据识别结果发送控制命令

## 三、程序运行

### 1. 启动BLE数据采集

**步骤1：** 确保脑电头环已开启并处于蓝牙配对模式

**步骤2：** 修改蓝牙设备名称

打开 `BLE/ble_reciveSINGLE2.py` 文件，修改第197行的设备名称：

```python
name = "BCI_BLE_CD380884"  # 替换为你的脑电头环蓝牙名称
```

**步骤3：** 启动数据采集

双击运行 `BLE/1.数据采集.bat` 文件，或在命令行中执行：

```bash
cd BLE
python ble_reciveSINGLE2.py
```

程序将开始搜索并连接脑电头环，成功连接后会显示接收到的脑电数据。

### 2. 启动SSVEP信号处理与识别

**步骤1：** 确保BLE数据采集程序已正常运行

**步骤2：** 启动SSVEP主程序

在命令行中执行：

```bash
cd SSVEP
python singlecommondssvep.py
```

**步骤3：** 填写实验信息

程序启动后会弹出实验信息对话框，请填写：
- 参与者姓名
- 性别
- 年龄
- 端口号（可选）

点击"确定"继续。

**步骤4：** 开始实验

在初始界面中，按空格键开始实验。屏幕中央会出现一个闪烁的方块（频率约为8Hz）。

**步骤5：** 专注观看闪烁方块

用户需要专注观看闪烁的方块，程序会自动采集脑电数据并进行识别。

**步骤6：** 查看识别结果

识别完成后，程序会在控制台输出识别结果和控制命令。

## 四、程序结构说明

### 1. BLE模块

- `ble_reciveSINGLE2.py`：蓝牙数据接收主程序
  - 搜索并连接脑电头环
  - 接收原始脑电数据
  - 解析数据并转换为LSL流

- `data_anlysis/data_to_float.py`：数据解析模块
  - `parse_egg()`：解析原始脑电数据
  - 提供滤波功能（陷波滤波、带通滤波）

### 2. SSVEP模块

- `singlecommondssvep.py`：主程序
  - 创建视觉刺激界面
  - 处理用户输入
  - 控制数据采集流程
  - 调用FBCCA算法进行识别
  - 生成控制命令

- `model.py`：FBCCA算法实现
  - `FBCCA`类：实现滤波器组典型相关分析算法
  - `fbcca_classify()`：SSVEP信号分类函数

- `lsl_received_data.py`：LSL数据接收程序
  - 接收LSL流数据
  - 保存数据到CSV文件

- `data_anlysis/data_to_float.py`：数据处理模块
  - 提供各种滤波函数

- `ssvep_car.py`：SSVEP数据处理程序（可选）

- `ssvep_game_control2.py`：游戏控制程序（可选）

## 五、技术参数

### 硬件参数

- 采样率：250Hz
- 通道数：1通道
- 蓝牙协议：BLE（低功耗蓝牙）

### 软件参数

- 视觉刺激频率：8Hz
- 数据预处理：
  - 陷波滤波：50Hz（去除工频干扰）
  - 带通滤波：6-70Hz（保留SSVEP相关频段）
- 识别算法：FBCCA（滤波器组典型相关分析）
- 滤波器组数：3组
- 典型相关分量数：1

## 六、常见问题与解决方案

### 1. 蓝牙连接失败

**问题**：BLE数据采集程序无法找到脑电头环

**解决方案**：
- 确保脑电头环已开启并处于蓝牙配对模式
- 检查蓝牙设备名称是否正确配置
- 确保电脑蓝牙功能正常
- 重启脑电头环和程序后重试

### 2. LSL数据流未找到

**问题**：SSVEP主程序无法找到LSL数据流

**解决方案**：
- 确保BLE数据采集程序已正常运行
- 检查LSL流类型是否为'EEG'
- 重启两个程序后重试

### 3. 识别精度低

**问题**：SSVEP信号识别准确率不高

**解决方案**：
- 确保用户处于安静环境中，减少干扰
- 调整视觉刺激亮度和对比度
- 确保用户注视点准确
- 可尝试调整滤波参数或FBCCA算法参数

### 4. 程序崩溃

**问题**：程序意外退出或崩溃

**解决方案**：
- 检查Python版本是否符合要求
- 确保所有依赖库已正确安装
- 查看控制台输出的错误信息
- 尝试重启程序

## 八、注意事项

1. **使用环境**：请在安静、光线适中的环境中使用程序
2. **电极放置**：确保脑电头环电极与头皮接触良好
3. **视觉疲劳**：长时间使用可能导致视觉疲劳，请适当休息
4. **数据保存**：实验数据会保存在 `SSVEP/eeg_data/temp.csv` 文件中
5. **退出程序**：按ESC键可随时退出程序

## 八、扩展程序

### 1. ssvep_car.py（脑控小车控制）

#### 功能概述

该程序实现了基于SSVEP的脑控小车功能，用户可以通过专注观看不同频率的闪烁方块来控制小车的各种动作。

#### 控制命令

程序提供6种控制命令，对应6种不同频率的闪烁方块：

| 命令 | 频率 | 功能 |
|------|------|------|
| 亮灯 | 8Hz  | 控制小车灯光开关 |
| 前进 | 9Hz  | 控制小车向前行驶 |
| 左转 | 10Hz | 控制小车向左转向 |
| 右转 | 11Hz | 控制小车向右转向 |
| 后退 | 12Hz | 控制小车向后行驶 |
| 鸣笛 | 13Hz | 控制小车鸣笛 |

#### 运行方法

1. 确保BLE数据采集程序已正常运行
2. 连接小车到电脑（通过USB或蓝牙）
3. 在命令行中执行：

```bash
cd SSVEP
python ssvep_car.py
```

4. 在弹出的对话框中填写实验信息和小车端口号
5. 按空格键开始实验
6. 专注观看对应的闪烁方块来控制小车

#### 配置说明

- 可以在程序中修改小车端口号（第18行：`baud_rate = 9600`）
- 可以调整闪烁块大小和位置（第109-110行：`size_w = 400`，`size_h = 400`）

### 2. ssvep_game_control2.py（脑控游戏控制）

#### 功能概述

该程序实现了基于SSVEP的脑控游戏功能，通过WebSocket与游戏客户端通信，用户可以控制游戏中的角色进行移动和发射操作。

#### 控制命令

程序提供3种控制命令，对应3种不同频率的闪烁方块：

| 命令 | 频率 | 功能 |
|------|------|------|
| 左 | 8Hz  | 控制角色向左移动 |
| 发射 | 9Hz  | 控制角色发射子弹 |
| 右 | 10Hz | 控制角色向右移动 |

#### 运行方法

1. 确保BLE数据采集程序已正常运行
2. 在命令行中执行：

```bash
cd SSVEP
python ssvep_game_control2.py
```

3. 在弹出的对话框中填写实验信息
4. 程序会自动启动WebSocket服务器（监听端口8767）
5. 按空格键开始实验
6. 在浏览器中打开`breakout_game.html`文件
7. 专注观看对应的闪烁方块来控制游戏

#### 技术说明

- 使用WebSocket协议与游戏客户端通信
- WebSocket服务器默认监听localhost:8767
- 支持多客户端连接
