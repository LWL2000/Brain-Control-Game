# 游戏使用文档

## 通用说明

所有游戏都已经按 SSVEP 控制节奏改成步进或回合制。游戏不会要求你在很短时间内反应，只有收到一次有效指令后才改变状态。

眼动/眼控不在网页游戏启动界面里选择。是否启用 EyeTrax、是否用 EyeTrax 覆盖 SSVEP 结果，都在 `3_ssvep_game_control.py` 启动时的参数对话框里选择。

SSVEP 数字指令固定为：

| 数字 | 动作 |
|---|---|
| `1` | 左 |
| `2` | 动作 |
| `3` | 右 |

键盘测试映射固定为：

| 键盘 | 动作 |
|---|---|
| `A` 或 `←` | 左 |
| `D` 或 `→` | 右 |
| `W`、`空格` 或 `Enter` | 动作 |
| `R` | 回到该游戏的 SSVEP 开始界面 |

## 1. 太空打陨石

文件：`1_space_shooter.html`

| 指令 | 动作 |
|---|---|
| 左 | 飞船左移一格 |
| 右 | 飞船右移一格 |
| 动作 | 向当前航道发射 |

敌机不会实时下落。每两次指令后，敌机会推进一格。

## 2. 接金币躲炸弹

文件：`2_coin_catcher.html`

| 指令 | 动作 |
|---|---|
| 左 | 篮子左移一格 |
| 右 | 篮子右移一格 |
| 动作 | 确认本轮接或躲 |

物品会停住等待。金币出现时，把篮子移到同一列后确认；炸弹出现时，把篮子移开后确认。

## 3. 三车道赛车

文件：`3_lane_racer.html`

| 指令 | 动作 |
|---|---|
| 左 | 切到左侧相邻车道 |
| 右 | 切到右侧相邻车道 |
| 动作 | 赛车前进一步 |

赛车不会自动前进。下一段路况提前显示，选好车道后再用动作指令推进一段。

## 4. 青蛙过河

文件：`4_frogger.html`

| 指令 | 动作 |
|---|---|
| 左 | 向左跳一格 |
| 右 | 向右跳一格 |
| 动作 | 向前跳一格 |

车流只在你发出指令后移动一拍，不会持续逼近。

## 5. 三轨打地鼠

文件：`5_whack_mole.html`

| 指令 | 动作 |
|---|---|
| 左 | 敲左洞 |
| 动作 | 敲中洞 |
| 右 | 敲右洞 |

地鼠会停住等待。它出现在哪个洞，就凝视对应目标完成敲击。

## 6. 节奏音符

文件：`6_rhythm_taps.html`

| 指令 | 动作 |
|---|---|
| 左 | 选择左轨音符 |
| 动作 | 选择中轨音符 |
| 右 | 选择右轨音符 |

这是慢拍校准，不是抢节奏。当前音符会一直等待，选择正确后才进入下一拍。

## 7. 贪吃蛇转向版

文件：`7_snake_turn.html`

| 指令 | 动作 |
|---|---|
| 左 | 向左转向 |
| 右 | 向右转向 |
| 动作 | 向当前方向前进一步 |

蛇不会自己移动。左右只改变朝向，动作指令才移动一格。

## 8. 迷宫寻宝

文件：`8_maze_treasure.html`

| 指令 | 动作 |
|---|---|
| 左 | 朝左旋转 |
| 右 | 朝右旋转 |
| 动作 | 向当前朝向前进一步 |

收齐 3 个宝石后到达出口即可完成。
