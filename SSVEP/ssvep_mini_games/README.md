# SSVEP 脑控小游戏合集

本文件夹包含 8 个按 SSVEP 范式改造的浏览器小游戏。所有游戏都采用慢节奏、离散动作、步进/回合制设计，避免普通游戏里抢反应的问题。

所有游戏均支持：

- 键盘测试：`A/←`、`D/→`、`W/空格/Enter`
- SSVEP WebSocket 控制：默认连接 `ws://localhost:8767`
- 固定命令映射：`1=左`、`2=动作`、`3=右`
- 每个游戏独立的 SSVEP 开始界面和开始按钮

眼动/眼控选项不在网页游戏界面里选择，而是在运行 `3_ssvep_game_control.py` 时的 PsychoPy 参数对话框里选择。Python 会决定最终发送 `1/2/3` 中哪个指令，网页游戏只负责接收最终指令。默认不显示 EyeTrax 红点或高亮框；勾选 `EyeTrax验证显示` 时才显示，用来检查真实眼动命中了哪个 SSVEP 目标。

## 快速使用

1. 运行 `3_ssvep_game_control.py`。
2. 在参数对话框里选择是否启用 `EyeTrax眼控`；需要排查逻辑时勾选 `EyeTrax验证显示`。
3. 打开 `index.html`，选择一个小游戏。
4. 点击小游戏自己的 SSVEP 开始按钮。
5. 页面右下角显示 `WebSocket 已连接` 后，即可接收 Python 发来的 `1/2/3` 指令。

## SSVEP 设计原则

- 游戏不会因为时间流逝自动失败。
- 大部分危险、目标、路线都会停住等待。
- 每识别出一次指令，游戏只执行一个离散动作。
- 游戏开始前必须点击专属的 SSVEP 开始按钮，避免刚连接时的误触指令直接开局。
